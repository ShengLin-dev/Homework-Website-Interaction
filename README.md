# 🤖 Interactive 3D Robot Website

An interactive 3D web project featuring a robot character that users can control and interact with directly in the browser.

## ✨ Features

* Interactive 3D robot
* Robot animations and movements
* Interactive buttons and UI controls
* 3D camera controls
* Responsive web interface
* Modern and simple UI design

## 🛠️ Technologies

* **React** — Front-end framework
* **JavaScript** — Application logic
* **Three.js / React Three Fiber** — 3D rendering
* **HTML / CSS** — Structure and styling
* **GLB / GLTF** — 3D model format

## 📂 Project Structure

```text
src/
├── components/    # UI and 3D components
├── assets/        # Images and 3D models
├── App.jsx        # Main application
└── main.jsx       # Application entry

public/            # Public assets
README.md          # Project documentation
```

## 🚀 Installation

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## 🎮 Interaction

Users can interact with the robot through the available buttons and controls.

For example:

**Button → React Event → Robot Action / Animation**

## 🎯 Project Goal

This project explores the combination of:

**Web Development + 3D Graphics + Animation + User Interaction**

It is created as an educational project to practice building interactive 3D experiences on the web.
